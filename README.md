# francis-gallo.github.io

Personal site of **Francis Gallo Sahayaraj**, Founding AI Engineer (intern) at Bulin AI, working on Physical AI and robot-learning tooling.

Live: **https://francis-gallo.github.io/**

A static site: `index.html` and `style.css`, with no build step, no framework and no external JS. It is deployed by
GitHub Pages from `main`. To preview it locally, run `python -m http.server` and open `http://localhost:8000`.
